    shell, así que Claude Code deja de preguntarte antes de hacerlo.

  Servidores MCP remotos en ~/.claude/.mcp.json:
    granola (mcp.granola.ai): recibe tu conversación cuando se usa
    chatprd (app.chatprd.ai): recibe tu conversación cuando se usa
  Herramientas, si faltan: git, Python, Node, pipx, gh, Claude Code,
    Obsidian, graphify, fastmcp
  Se actualiza solo desde GitHub cada pocos días, con hooks nuevos.

El mismo sí cubre lo que agrega la entrevista: tu vault, sus plugins de
Obsidian y hooks, un respaldo del vault, un chequeo de tu diario que
Claude corre cada día a una hora programada, y:
  Semanal y mensual (insights): Claude Code corre sin supervisión, con
    permiso para editar archivos y correr comandos de shell.
Aparte: conectores (email, calendario, Slack) y registro por email.

Sin versión fija: las partes de terceros instalan su versión más nueva.
Respaldos: los archivos de configuración se copian antes de cada cambio.

Claude Code te puede pedir permiso para algunos de estos pasos. Esos
avisos son entre vos y Claude Code. No los voy a contestar por vos ni
te voy a decir qué elegir.

Respondé "sí" para instalar todo esto, o "no" para no instalar nada.
